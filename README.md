# Raqamli maktab platformasi

Maktab boshqaruvi uchun zamonaviy UX/UI asosidagi platforma. Loyihada o‘quvchilar bazasi, davomat monitoringi, murojaatlar, inventar va hisobotlar mavjud.

## Tezkor ishga tushirish

Serversiz variant uchun repozitoriydagi `index.html` faylini yuklab olib, brauzerda oching. Kiritilgan ma’lumotlar brauzerning `localStorage` xotirasida avtomatik saqlanadi.

## To‘liq loyiha

```bash
pnpm install
pnpm dev
```

So‘ng `http://localhost:3000` manzilini oching.

## Imkoniyatlar

- o‘quvchilar ma’lumotlar bazasi;
- davomat diagrammalari va xavf signallari;
- murojaatlar holatini kuzatish;
- inventar nazorati;
- qidiruv, CSV va JSON eksport;
- mobil qurilmalarga mos responsive dizayn;
- Cloudflare D1 ma’lumotlar bazasi integratsiyasi.
